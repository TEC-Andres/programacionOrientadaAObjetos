# SHA-256 Hash Function

## module description
this module handles security tasks by hashing incoming user credential strings into unique signatures instead of saving plaintext files.

## verification procedure
the program secures login entry streams using this simple procedure:
* step 1: intercepts the raw string inputs typed into the password fields.
* step 2: injects the string payload directly into the sha256 encryption calculation engine.
* step 3: returns a fixed 64-character long signature to the calling application loop.
* step 4: matches the calculated value against the entry key stored inside the user database file.
