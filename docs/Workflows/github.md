# Github guidelines

## module description
this document establishes the quality control protocols, merge checklists, and assignment standards implemented inside the shared github repository.

## pull request merge checklist
to merge software changes into upstream branches, fulfill this simple procedure:
* step 1: submit your updates through an isolated pull request.
* step 2: write an analytical summary documenting which assets were changed.
* step 3: verify that all automated unit test files compile successfully.
* step 4: secure a peer review clearance mark before checking code into integration branches.
