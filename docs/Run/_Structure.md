# Compilation and Execution Structure

This document outlines the structure and requirements for compiling and running the application. It includes the necessary steps and prerequisites for both the compilation and execution processes.

The structure of the application is as follows:
- `__release__` - Contains the compiled binaries and configuration files.
- `db/rawData/` - Contains the raw data for the database.
- `__release__/environments/` - Contains the environment-specific executables.
